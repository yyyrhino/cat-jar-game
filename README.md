# 猫猫罐

[在线试玩](https://yyyrhino.github.io/cat-jar-game/)

0.4.1 新增随机原地大跳与空中碰触扣分，并加强起跳前的晃罐提示。

一个轻松的摸猫网页小游戏。黑猫随机从三个蓝色罐子之一探头或原地大跳，四指手套跟随鼠标，摸到探出的猫头时会轻轻抚摸，小猫闭眼享受。

## 玩法

- 小猫回缩或落罐后等待随机 **0.5–3 秒**，再从另一个罐子出现。每次随机选择普通探头（**50%**）或大跳（**50%**）。
- 完全探出后停留随机 **1.5–2.5 秒**；探出和回缩各用时 **0.15 秒**。
- 在停留期间第一次摸到猫头，本次停留额外延长 **1 秒**。每次探头只延长一次，连续点击不会叠加。
- 按住猫头，每秒累计 **20 点好感**；不足一秒也按实际时间累计。松开、移出或回缩停止累计，上限为 100 点。
- 大跳前，起跳罐晃动 **0.85 秒**作为提示。随后小猫用 **0.24 秒**出罐，在空中团成无尾巴的小球，飞行 **1.1 秒**，再用 **0.24 秒**落罐。每次大跳都从原罐垂直跳起并落回原罐，不再跨罐跳跃。
- 空中的小猫不能抚摸。鼠标无论是否按下，只要触碰到空中小猫，就一次扣除 **30 点好感**，最低为 0。**每次大跳最多扣一次**，鼠标持续停留或移开后再次碰到都不会重复扣分；下一次大跳重新计算。
- 达到 100 点立即结束抚摸并进入 **4.6 秒**结束反馈：猫猫飞出、罐子退去，猫眼发光并以蓝灰色光照亮全屏。结束反馈期间停止探头和好感累计。
- 随后好感清零，以 **1.1 秒**回到初始画面，再等待随机间隔开始下一轮。右上角重置也可以随时打断结束反馈并直接重新开始。
- 点击空白或罐子不会扣分。右上角环形箭头会清空好感并重新开始。
- 切到后台时暂停；返回后继续。当前版本不保存刷新前的进度。

## 本地运行

安装 Node.js 20 或更新版本，在此目录运行：

```sh
node server.mjs
```

然后打开 <http://127.0.0.1:4180/>。Windows 也可以双击 `打开猫猫罐.cmd`。
网页使用浏览器 ES 模块和 WebGL，需要通过网页地址打开，不能直接双击 HTML 文件。

## 测试

```sh
node --test
```

测试覆盖随机停留与动作选择、临近回缩的有效触摸、单次延长、每秒 20 点好感累计、三个罐子的原地跳跃、空中单次扣分与下限、跨阶段计时和复位，以及满好感结束反馈与再次游玩。

## GitHub Pages

本项目无需安装依赖或编译。将项目推送到 GitHub 后，在仓库 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)** 并保存。
根目录的 `.nojekyll` 让 GitHub 直接发布静态文件。网页资源使用相对路径，适用于仓库子路径。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` / `styles.css` | 页面布局、好感条和视觉样式 |
| `app.js` | 页面与游戏连接、重置、加载提示 |
| `gameplay.js` | 随机探头/大跳循环、触摸延时奖励、好感计时、空中扣分和结束反馈状态 |
| `scene.js` | Three.js 模型、罐口约束、眼睛表情和触摸判定 |
| `hand.js` | 四指 SVG 手套与轻抚动画 |
| `finale.js` / `finale.css` | 满好感时的双眼发光、全屏蓝灰光和返回过渡 |
| `tests/gameplay.test.js` / `tests/jump.test.js` | 探头、跳跃、好感与结束反馈测试 |
| `vendor/` | 本地 Three.js 与原始许可 |

背景为黑色，罐子 `#38BAEB`，描边 `#5C33FD`，眼白 `#C0F1FC`，手套 `#C0F0FB`。
猫和罐子由代码生成，手套为 SVG；页面不依赖外部字体、贴图、分析服务或 CDN。
Three.js 0.170.0 的 MIT 许可保留在 `vendor/THREE-LICENSE.txt`。
