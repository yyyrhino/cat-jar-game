# 猫猫罐

[在线试玩](https://yyyrhino.github.io/cat-jar-game/)

0.5.0 加入右键翻掌接猫：接住下落的猫，再次右键放回原罐，获得 40 点；在接触前 0.2 秒内按下右键，另奖励 20 点。好感上限提高为 200，悬停不再扣分，左键拍到扣 30，漏接落地扣 10。保留上一版的几何缓存与轻量碰撞优化。

一个轻松的摸猫网页小游戏。黑猫随机从三个蓝色罐子之一探头或原地大跳，四指手套跟随鼠标，摸到探出的猫头时会轻轻抚摸，小猫闭眼享受。

## 玩法

- 小猫回缩或落罐后等待随机 **0.5–3 秒**，再从另一个罐子出现。每次随机选择普通探头（**50%**）或大跳（**50%**）。
- 完全探出后停留随机 **1.5–2.5 秒**；探出和回缩各用时 **0.15 秒**。
- 在停留期间第一次摸到猫头，本次停留额外延长 **1 秒**。每次探头只延长一次，连续点击不会叠加。
- 探头时用左键按住猫头，每秒累计 **20 点好感**；不足一秒也按实际时间累计。松开、移出或回缩停止累计，上限为 **200 点**。
- 大跳前，起跳罐晃动 **0.85 秒**作为提示。小猫在罐内团成无尾巴的小球，从出罐到落回罐内共 **0.92 秒**，使用连续的重力曲线：快速弹出、上升减速、到顶点后加速下落，落罐前不再突然减速。每跳高度按屏幕空间确定，出罐和回罐的分段时长由轨迹自然计算。每次大跳都从原罐垂直跳起并落回原罐，不跨罐跳跃。
- 空中的小猫不能抚摸。**左键点中**空中小猫才会扣除 **30 点好感**，每次大跳最多一次，最低为 0。普通悬停、擦过、提前按着左键都不会触发拍击。
- 按住右键，手翻成朝上的托掌，只有**下落**的猫能被接住。提前按住接住后，放回获得 **40 点**；若接触时距本次按下右键不超过 **0.2 秒**，视为及时接住，放回共得 **60 点**。长按不会重复刷新及时判定窗口。
- 接住后可以松开右键，小猫会一直留在手上，随鼠标移动；**再次右键**用 0.6 秒放回原罐。先对准罐口，再下降，完成后只结算一次奖励。托举期间没有被动加分。
- 没接住而自然落回罐子，在落地完成时扣 **10 点**，每跳一次。拍到后也未接住则合计扣 40 点；最低仍为 0。普通探头回缩不扣分。
- 拍到后，小猫的双眼立刻变成叉叉，表现为轻微受伤；接住或落罐后恢复。仍可以在下落时接住它，之前扣除的 30 点保留，成功放回正常结算奖励且不再扣漏接的 10 点。拍击不会延长或打断跳跃。
- 达到 **200 点**立即进入 **4.6 秒**结束反馈：猫猫飞出、罐子退去，猫眼发光并以蓝灰色光照亮全屏。结束反馈期间停止探头和好感累计。
- 随后好感清零，以 **1.1 秒**回到初始画面，再等待随机间隔开始下一轮。右上角重置也可以随时打断结束反馈并直接重新开始。
- 点击空白或罐子不会扣分。右上角环形箭头会清空好感并重新开始。
- 切到后台时暂停；返回后继续。当前版本不保存刷新前的进度。
- 接猫操作目前面向带右键的鼠标；小屏布局可用，但尚未加入纯触屏接猫手势。

## 本地运行

安装 Node.js 20 或更新版本，在此目录运行：

```sh
node server.mjs
```

然后打开 <http://127.0.0.1:4180/>。Windows 也可以双击 `打开猫猫罐.cmd`。
网页使用浏览器 ES 模块和 WebGL，需要通过网页地址打开，不能直接双击 HTML 文件。

## 测试

```sh
node --test
```

测试覆盖随机停留与动作选择、有效触摸与单次延长、每秒 20 点好感累计、原地跳跃与连续重力、空中拍击与漏接扣分、受伤表情、仅下降可接、托举冻结、40/60 点放回奖励、重置取消未结算奖励，以及 200 点结束反馈与再次游玩。

## GitHub Pages

本项目无需安装依赖或编译。将项目推送到 GitHub 后，在仓库 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)** 并保存。
根目录的 `.nojekyll` 让 GitHub 直接发布静态文件。网页资源使用相对路径，适用于仓库子路径。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` / `styles.css` | 页面布局、好感条和视觉样式 |
| `app.js` | 页面与游戏连接、重置、加载提示 |
| `gameplay.js` | 随机探头/大跳循环、触摸延时奖励、好感计时、空中扣分和结束反馈状态 |
| `jump-motion.js` | 统一重力轨迹、罐口净空时刻和跳跃分段时长 |
| `scene.js` | Three.js 模型、罐口约束、眼睛表情和触摸判定 |
| `hand.js` | 四指 SVG 手套与轻抚动画 |
| `finale.js` / `finale.css` | 满好感时的双眼发光、全屏蓝灰光和返回过渡 |
| `tests/gameplay.test.js` / `tests/jump.test.js` / `tests/jump-motion.test.js` / `tests/catch.test.js` | 探头、跳跃运动、接猫、好感与结束反馈测试 |
| `vendor/` | 本地 Three.js 与原始许可 |

背景为黑色，罐子 `#38BAEB`，描边 `#5C33FD`，眼白 `#C0F1FC`，手套 `#C0F0FB`。
猫和罐子由代码生成，手套为 SVG；页面不依赖外部字体、贴图、分析服务或 CDN。
Three.js 0.170.0 的 MIT 许可保留在 `vendor/THREE-LICENSE.txt`。
